## 📖 드럼 탭(악보) 읽는 법

악보는 이렇게 생겼습니다. 왼쪽이 악기, 가로 한 줄이 **한 마디**예요.

```
        1 & 2 & 3 & 4 &
크래시  X · · · · · · ·
하이햇  x x x x x x x x
스네어  · · o · · · o ·
베이스  o · · · o · · ·
```

### 악기 (왼쪽)
- **크래시** = 큰 심벌 (섹션 시작할 때 "쾅")
- **하이햇** = 발로 닫은 하이햇 (계속 "칙칙칙")
- **스네어** = 가운데 통통한 북 ("탁")
- **베이스** = 발로 밟는 큰 북 ("둥")
- **하이탐 / 플로어탐** = 필인(채우기)에 쓰는 통

### 기호
- `x` , `o` , `X` = **친다** (그 자리에서 소리 냄)
- `·` = **안 친다** (쉼)
- 위/아래 같은 칸에 있으면 **동시에** 친다

### 박자 세는 법
맨 윗줄 `1 & 2 & 3 & 4 &` = 입으로 **"원 앤, 투 앤, 쓰리 앤, 포 앤"**
- 숫자(1·2·3·4) = "정박"
- `&`(앤) = 정박 사이 "엇박"
- 한 칸이 8분음표 하나입니다.

## 🥁 모든 곡에 통하는 "초보 만능 패턴"

곡이 어려우면 **이 두 가지만 칠 줄 알아도 콘티 전체를 반주할 수 있습니다.**

### ① 왕초보 버전 (4분음표만 — 제일 쉬움)
손발을 천천히, 또박또박.
```
        1 2 3 4
하이햇  x x x x
스네어  · o · o      ← 2박, 4박에 스네어
베이스  o · o ·      ← 1박, 3박에 베이스
```

### ② 기본 8비트 (워십의 90%는 이걸로 됨)
```
        1 & 2 & 3 & 4 &
하이햇  x x x x x x x x
스네어  · · o · · · o ·      ← 2박, 4박
베이스  o · · · o · · ·      ← 1박, 3박
```

> 💡 **핵심 규칙:** 스네어는 **항상 2박과 4박**. 이것만 지켜도 곡이 그루브 있게 들립니다.
> 베이스는 곡에 맞춰 자유롭게 추가하면 됩니다.

## 🔁 곡 구성 따라가기 (워십 공통)

워십은 보통 이 순서로 흘러갑니다. **인도자(싱어)를 보고 따라가는 게 가장 중요**합니다.

```
전주(Intro) → 1절 → 후렴 → 2절 → 후렴 → 브릿지 → 후렴 반복 → 엔딩
 (작게)      (작게)(커짐)        (커짐)  (제일 큼)        (마무리)
```

- **절(Verse)** = 조용히. 하이햇 살살, 베이스 단순하게.
- **후렴(Chorus)** = 커짐. 라이드나 크래시로 열어주고 힘 있게.
- **브릿지(Bridge)** = 곡의 절정. 가장 크고 꽉 차게.
- **섹션이 바뀌는 첫 박**에 **크래시 1번** 쳐주면 자연스럽게 연결됩니다.

## 🥢 제일 쉬운 필인(채우기) 3가지

마디 끝(보통 4박)에서 다음 섹션으로 넘어갈 때 "드르륵" 하고 채워주는 것.

**필인 1 — 스네어 4번 (제일 쉬움)**
```
        1 & 2 & 3 & 4 &
스네어  · · · · · · o o o o   (4박을 8분음표로 다다다닥)
```

**필인 2 — 통으로 내려오기**
```
        ... 3 e & a 4 e & a
스네어      o o
하이탐          o o
플로어탐            o o
```

**필인 3 — 그냥 크래시 (필인이 어려우면 이걸로)**
```
넘어가는 첫 박에 크래시 "쾅!" + 베이스 동시에.  → 이거면 충분합니다.
```

## 🧑‍🎓 초보자 연습 순서 (추천)

1. **음원을 여러 번 듣기** — 박자(빠르기), 어디가 절·후렴인지 귀로 익히기
2. **메트로놈에 맞춰 기본 8비트만** 느린 템포로 (악보 BPM의 70%부터)
3. 곡 따라 **8비트 계속 치며 끝까지 멈추지 않기** (제일 중요!)
4. 익숙해지면 **섹션 시작에 크래시**, **섹션 끝에 필인** 추가
5. 마지막으로 곡별 베이스 패턴/셈여림 다듬기

> ⛳ **초보 1순위 목표:** 화려함보다 **안 멈추고 박자 지키기**.
> 틀려도 멈추지 말고 다음 마디로 가세요. 그게 드러머의 가장 중요한 일입니다.
